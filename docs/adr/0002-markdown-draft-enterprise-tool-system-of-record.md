# Markdown is the working draft; the enterprise tool is the system of record after publication

Requirements are drafted, traced and verified as markdown in the workspace because that is where AI works best (diffable, portable, tool-independent). On approval they are published to the enterprise delivery tool (Jira/ADO/Confluence), which becomes the system of record. We rejected making the enterprise tool the system of record from day one, because it would tie the whole library to one tool's API before its value was proven.

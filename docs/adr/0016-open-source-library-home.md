# The library lives in this public repository as open source

BA-skills is published from `github.com/ImaginaryBA/BA-skills` under the company's open-source program, and stakeholder-facing outputs link to its `CONTEXT.md` there. This replaces the earlier plan to move the library to a company git host after the pilot. Because the repository is public, it holds no company-specific content (templates, names, classification levels, runtime lists) and quotes no BABOK text: BABOK is cited by section number and name only.

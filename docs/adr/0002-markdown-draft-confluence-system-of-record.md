# Markdown is the working draft; Confluence is the system of record after publication

Requirements are drafted, traced and verified as markdown in the workspace because that is where AI works best (diffable, portable, tool-independent). On approval they are published to Confluence as markdown-derived documents, and Confluence becomes the system of record. Publication starts as a manual step done by the BA; direct publication through a connector is a possible future version, not the starting point, so the library is not tied to one tool's API before its value is proven.

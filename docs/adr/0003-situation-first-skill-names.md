# Skills are named by BA situation, with BABOK as metadata

Skill names and descriptions use the words a BA would use to ask for help ("turn interview notes into requirements"), because the description is what makes a skill trigger. Each skill carries its BABOK reference (knowledge area, task, techniques) as metadata, which keeps coverage of all six knowledge areas demonstrable. We rejected organising and naming skills by BABOK knowledge area, because BAs don't describe their work that way.
